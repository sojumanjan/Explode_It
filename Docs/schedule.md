## 1주차 (9/30 ~ 10/6) — 핵심 루프와 기반 [완료]

**목표: "1초 뒤를 읽고 던지는" 재미 검증**

- 플레이어 이동, 구르기 회피, 입력 체계(Input System)
- 1초 딜레이 폭탄, 폭발 범위 표시와 판정
- 적 AI 상태 머신(이동 → 예고 → 공격), 흐름장 기반 경로 추적
- 적 4종: 전사, 궁수, 저격수, 방패병
- 웨이브·군집 데이터 구조, 처치 수 기반 진행(100마리 → 보스전)
- 특수 능력 블랙홀
- UI·HUD, 씬 흐름, 사운드 데이터화, BGM
- 캐릭터 스프라이트, 상태별 트윈 모션, 사망 연출
- 보스 2종: 야수, 드릴 광부 / 보스 등장·사망 연출
- 웨이브 1·2 작성, 개발자 패널

## 2주차 (10/7 ~ 10/13) — 콘텐츠 확장과 스토리 [완료]

**목표: 스토리 모드 한 판(웨이브 4개 + 보스 4전) 완성**

완료

- 적 2종 추가: 사마귀, 돌격병 / 스폰 구역별 맵 입구
- 보스 추가: 화염 마법사
- 무기 5종: 기본, 빠른연사, 큰폭발, 폭탄3개, 더블배럴
- 웨이브 3·4 작성 → 스토리 웨이브 4개 완성
- 스토리 모드 구조(보스 4전 → 엔딩), 세계관 확정
- 왕 보스 등장 대화(클릭 진행, 표정 9종), 전투 중 왕 컷인

- 최종 보스 "각성한 왕": 변신 연출, 3국면 패턴
- 엔딩 연출(책 속으로 → 낮·밤 만화 → 청구서 편지 → THE END...?)
- 아티팩트 데이터 구조와 적용

## 3주차 (10/14 ~ 10/20) — 진행 시스템과 무한 모드 [완료]

**목표: 반복 플레이 동기 완성 → 주말 콘텐츠 동결**

- 저장: 업적·해금 정보 로컬 저장(웹은 브라우저 저장소)
- 업적 시스템, 무기·아티팩트 해금
- 타이틀, 모드 선택, 판 시작 전 무기·아티팩트 선택 화면
- 무한 모드: 실시간 절차적 웨이브 생성기, 보스 강화 로테이션
- 하드모드(승천): 저주 9종 + 왕관 → 왕 결전 → 찐엔딩 크레딧
- 도감(스티커 30장)
- 콘텐츠 동결

## 4주차 (10/21 ~ 10/27) — 완성도와 배포 [완료]

**목표: itch.io 웹 빌드 공개**

- 플레이 기록 수집(Unity Analytics, 첫 실행 동의 창), 플레이 테스트 설문(한/영 폼)
- 빌드 용량 줄이기(안 쓰는 에셋 삭제, 텍스처 압축, BGM 품질): Windows 262MB → 230MB
- 찐엔딩 크레딧 연출(곡 길이에 맞춘 글 속도, 곡 끝 잔향), 타이틀 로고, 버튼 디테일
- 손맛(멀티킬 숫자, 처치 수 튀기, 체력 1칸 경고), 설정(번쩍임 줄이기, 자동 일시정지, 조작법, 전체화면·해상도)
- 스토리 중간부터 시작(보스 처치마다 시작 지점 저장)
- 30초 소개 영상, NC AI 뉴딜 아카데미 발표(10/27)

## 일정 관리 원칙

- 밸런스 수치는 모두 데이터(ScriptableObject)로 빼 두어, 후반 조정에 코드를 건드리지 않는다.
- 현재 주차 범위를 벗어나는 기능은 아이디어만 기록하고 구현하지 않는다.
- AI가 만든 결과를 고치거나 버린 경우 개발 일지에 기록한다.
