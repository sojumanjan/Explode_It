# 사운드 음량 표 (2026-11-14 측정)

Unity가 임포트한 샘플(실제 재생되는 소리)을 그대로 읽어 잰 값이다. 단위는 dBFS이고 0이 최대, 낮을수록 작다.

- **최대 0.3초**: 가장 시끄러운 0.3초 구간의 RMS. 짧은 효과음은 전체 RMS보다 이 값이 체감에 가깝다
- **실제 크기** = 최대 0.3초 + SO 볼륨(dB로 환산). 효과음끼리, 배경음끼리 비교하는 값이다. 설정창 볼륨은 모두에 똑같이 곱해지므로 뺐다
- **기준**: 게임 중 효과음(UI·배경음 제외) 실제 크기의 중앙값 -13.5. 이보다 6dB 넘게 크면 🔺, 6dB 넘게 작으면 🔻
- 사람 귀의 주파수 감도(LUFS의 K 가중)는 반영하지 않은 단순 RMS라, 저음이 많은 소리는 숫자보다 작게 들릴 수 있다
