# 포트폴리오 재료 목록

이 프로젝트에서 얻은 기술, 기획 능력을 항목별로 모아 두는 창고다. 나중에 회사별 맞춤 포트폴리오를 쓸 때 몇 개씩 골라 쓴다.
본문은 노션에 쓰고, 여기에는 무엇을 썼는지와 다음에 쓸 것만 기록한다. (2026-10-29 작성, 10-30 갱신)

## 쓰는 형식

- 항목마다: **문제 → 판단 → 구현 → 배운 점 → 결과**, 문체는 "~다"
- **숫자와 설명은 최종 게임 기준**으로 쓴다(10-30 결정). 시간 순서 일지가 아니라 주제별 창고라서다
  - 과정이 핵심인 항목은 "처음 → 최종"을 살린다(예: 웨이브 구조 4번 개편, 업적 3개 → 30개)
  - GIF는 개발 중 화면이어도 된다. 캡션에 "개발 초반 화면"이라고 적는다
  - 예외: 9번 프로파일링은 측정한 버전(10/7)을 밝힌다
- 노션 데이터베이스 속성: 분야(기술/기획/둘 다), 키워드, 기간, 근거(커밋, 파일, GIF), 수치, 한 줄 요약
- 짧게 쓴다. 길면 핵심만 남기고 줄인다
- 가운뎃점 기호를 쓰지 않는다. 나열은 쉼표나 "와/과"로
- 숫자는 근거가 있는 것만 쓴다. 에디터 측정값은 "에디터 측정"이라고 밝힌다

- 노션 번호 목록이 전부 "1."로 보이는 곳: → 줄을 Tab으로 들여쓴다

9번 측정값 (10/7 버전 `83d79de`, 에디터 플레이 모드, 적 약 92마리, 2,000프레임)

- 프레임당 평균: `EnemyVisual` 0.17ms, `Enemy` 0.14ms, `FlowField` 0.003ms (최대 0.075ms)
